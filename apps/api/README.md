# RecoveryOS API

Backend API service for RecoveryOS — Payment Reliability & Revenue Recovery Control Plane.

## Tech Stack
- Python 3.12+ / 3.13
- FastAPI
- Pydantic v2 & Pydantic Settings
- SQLAlchemy 2.x (Async)
- PostgreSQL (via asyncpg)
- Redis (via redis-py async)
- Alembic for database migrations
- Pytest, Ruff, Mypy
